# MPC Sampler

Windows 向けの MPC 風パッド型サンプラーソフトウェアです。
wav および mp3 ファイルを読み込み、PCのキーボードやマウスで再生できます。

## 動作環境

- Windows 10 / 11
- インターネット接続不要（ローカル完結）

## 機能

- **16個のパッド** に音声を割り当て可能
- **wav / mp3** 形式の音声ファイルに対応
- **同時発音** に対応（複数パッドの同時再生、連打可能）
- **キーボード入力** での再生に対応（Q, W, E, R... など）
- パッドごとの **音量調整** およびマスター音量調整
- 割り当て設定の **自動保存・復元**

## 使い方

1. `MPCSampler.exe` を起動します。
2. 各パッドの下にある **「📂」ボタン** をクリックし、音声ファイル（.wav または .mp3）を選択します。
3. パッドをクリックするか、パッド右上に表示されているキーボードのキーを押すと、音が鳴ります。
4. パッド下部のスライダーで、パッドごとの音量を調整できます。
5. 画面下部の「MASTER VOL」スライダーで、全体の音量を調整できます。
6. 設定はアプリ終了時に自動で保存されます。手動で保存・読み込みを行いたい場合は、画面右下の「💾 保存」「📂 読込」ボタンを使用してください。

## 設定ファイルの保存場所

デフォルトの設定ファイルは以下の場所に保存されます：
`C:\Users\<ユーザー名>\Documents\MPCSampler\settings.json`

## ソースコードからの起動方法（開発者向け）

Python 3.11 以上が必要です。

```bash
# 必要なライブラリのインストール
pip install pygame miniaudio numpy PyQt5 pyinstaller

# 起動
python main.py
```

## exe化手順（開発者向け）

Windows環境でビルドするには、以下の2つの方法があります。

### 方法1: 付属のバッチファイルを使用する（推奨）
ソースコードと同じフォルダにある `build_windows.bat` をダブルクリックして実行してください。
必要なライブラリのインストールからexe化まで自動で行われます。
完了後、`dist` フォルダ内に `MPCSampler.exe` が生成されます。

### 方法2: コマンドプロンプトで手動実行する
「`pyinstaller` が認識されない」エラーを防ぐため、`python -m PyInstaller` を使用します。

```cmd
# 1. 必要なライブラリのインストール
python -m pip install pygame miniaudio numpy PyQt5 pyinstaller

# 2. ビルドの実行
python -m PyInstaller --noconfirm mpc_sampler.spec
```
完了後、`dist` フォルダ内に `MPCSampler.exe` が生成されます。
